# AI-ресепшн 24/7 — демо

В репозитории два демо:
- **веб-чат** для салона красоты и фитнес-клуба (этот раздел);
- **Telegram-бот для барбершопа** с записью на свободные слоты и панелью мастера — [см. ниже](#telegram-бот-для-барбершопа).


Чат-бот администратор для салона красоты или фитнес-клуба. Пишет как живой человек: коротко, тепло, со смайликами, может поболтать и всегда возвращает к записи.

Умеет:
- отвечать про услуги, цены, мастеров/тренеров, адрес, часы работы, акции;
- подбирать услугу или абонемент;
- записывать (собирает услугу, время, имя, телефон и подтверждает запись), переносить и отменять;
- поддерживать small talk.

Два демо-бизнеса в одной ссылке:
- `/` или `/?b=salon` — студия красоты «Лаванда»
- `/?b=fitness` — фитнес-клуб «PulseFit»

> Это демо: запись не уходит в реальную CRM, свободные слоты бот придумывает правдоподобно.

## Запуск локально

Нужен Node.js 20+ и ключ Anthropic API ([console.anthropic.com](https://console.anthropic.com)).

```bash
cp .env.example .env   # вписать ключ
npm start              # http://localhost:3000
```

Веб-чату зависимости не нужны (`npm install` нужен только Telegram-боту, см. ниже).

## Деплой в один клик (ссылка для клиентов)

1. Зайти на [vercel.com](https://vercel.com) → **Add New → Project** → выбрать этот репозиторий.
2. В **Environment Variables** добавить `ANTHROPIC_API_KEY`.
3. **Deploy**. Получите ссылку вида `https://ai-reception-xxx.vercel.app` — её можно отправлять клиентам.

## Как адаптировать под конкретного клиента

Всё в одном файле — `lib/businesses.js`: название, имя администратора, приветствие, кнопки-подсказки, адрес, услуги и цены. Поменяйте текст и задеплойте заново.

Модель по умолчанию — `claude-sonnet-5-5`, можно сменить переменной `ANTHROPIC_MODEL` (например, `claude-haiku-5-5` — быстрее и дешевле).

## Структура

```
public/index.html   — страница чата (мессенджер-стиль, без фреймворков)
api/chat.js         — бэкенд: POST /api/chat (Vercel-функция)
api/config.js       — шапка и приветствие для выбранного бизнеса
lib/businesses.js   — данные бизнесов (правьте здесь)
lib/chat.js         — промпт и запрос к Claude
server.js           — локальный сервер
```

# Telegram-бот для барбершопа

Живой ИИ-администратор в Telegram без кнопок-шаблонов: клиент пишет как обычно, бот отвечает по-человечески и записывает.

Что умеет:
- отвечает про услуги, цены, адрес, часы работы, мастеров и прочие «знания» точки;
- показывает свободные окна и записывает на выбранную услугу. Каждая услуга занимает 1–4 слота подряд (стрижка — 2 слота по 30 мин, «стрижка + борода» — 3, комплекс — 4);
- показывает и отменяет записи клиента, за 2 часа до визита присылает напоминание;
- присылает мастеру в Telegram уведомление о каждой новой записи и отмене;
- перед ответом «печатает» — время пропорционально длине ответа, но не дольше 4 секунд;
- если не уверен в ответе, ИИ не ответил вовремя или клиент прислал голосовое/фото — **молчит и зовёт мастера**: присылает карточку с перепиской и черновиком ответа;
- точка — это данные, а не код: её можно импортировать с Яндекс.Карт, поправить словами или фото прайса и передать другому мастеру.

> Пока точка не настроена, бот работает на демо-данных барбершопа «Бритва» с правдоподобно занятыми слотами. Записи хранятся в самом боте (`data/state.json`), во внешнюю CRM не уходят.

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) (`/newbot`) и скопируйте токен.
2. Заполните `.env`:
   ```bash
   cp .env.example .env   # ANTHROPIC_API_KEY и TELEGRAM_BOT_TOKEN
   npm install
   npm run bot
   ```
3. В логе появится ссылка «стать владельцем» (`https://t.me/<бот>?start=own_…`). Откройте её — вы владелец, бот покажет панель мастера. Вместо ссылки можно сразу вписать свой Telegram ID в `OWNER_IDS`.

Бот работает через long polling — нужен постоянно запущенный процесс (VPS, Railway, Render, Fly.io, Docker), Vercel для него не подходит. Сервер должен быть в стране, где доступен Anthropic API. Данные лежат в `data/state.json` — эту папку нужно сохранять между перезапусками.

```bash
docker build -t barber-bot .
docker run -d --restart=always --env-file .env -v $(pwd)/data:/app/data barber-bot
```

### Автодеплой на свой сервер

Push в `main` → GitHub Actions ([`.github/workflows/deploy.yml`](.github/workflows/deploy.yml)): `npm test` и проверка запуска веб-чата, затем сервер по SSH получает команду выложить этот коммит. Сервер сам забирает его из GitHub, собирает образ из `Dockerfile`, перезапускает бота и ждёт в логе «Бот @… запущен»; если бот не поднялся — откатывается на предыдущую рабочую версию. Ручной запуск — Actions → Test and Deploy → Run workflow.

Секреты репозитория: `DEPLOY_SSH_KEY` (ключ, которому на сервере разрешена только выкладка), `DEPLOY_KNOWN_HOSTS` (ключ хоста), `DEPLOY_TARGET` (`пользователь@хост`).

## Панель мастера

Команды: `/panel`, `/chats`, `/bookings`, `/settings`, `/help`.

- **Ждут ответа** — переписки, где бот замолчал и позвал мастера.
- **Мои** — переписки, которые мастер сейчас ведёт сам.
- **Текущие** — все переписки за последние сутки.
- **Незавершённые** — клиент писал за последнюю неделю, но так и не записался.
- В карточке переписки: «Перехватить» / «Взять диалог» (бот замолкает, сообщения мастера уходят клиенту), «Вернуть боту», «Отправить черновик», «Бот, попробуй ещё», «Завершить диалог». Перехватить можно снова в любой момент.
- Ответ реплаем на уведомление уходит этому клиенту.
- **Записи** и **Свободные окна** — просмотр и отмена записей (клиент получит сообщение).

Если вы проверяете бота один и за клиента, и за мастера, создайте второго бота и укажите его токен в `ADMIN_BOT_TOKEN` — панель переедет туда, а основной бот будет вести себя с вами как с клиентом.

## Как не ставить «прочитано» (Telegram Business)

В обычном чате с ботом Telegram сам отмечает сообщения прочитанными — бот на это повлиять не может. Поэтому в обычном режиме бот при неуверенности просто молчит и зовёт мастера.

Чтобы сообщения действительно оставались **непрочитанными**, подключите бота к личному аккаунту мастера через Telegram Business (Premium не нужен):

1. Настройки → Telegram для бизнеса → Чат-боты → выбрать своего бота.
2. Разрешить боту отвечать на сообщения и отмечать их прочитанными.
3. Выбрать, в каких чатах бот работает (например, во всех, кроме контактов).

Тогда бот отвечает клиентам прямо из личного аккаунта мастера и отмечает сообщение прочитанным только когда уверенно ответил. Если бот позвал мастера — сообщение висит непрочитанным, как будто мастер его ещё не видел. Если мастер ответил клиенту сам — бот в этом чате замолкает, пока его не вернут кнопкой.

## Смена точки и передача мастеру

Всё делается из Telegram, в «Настройки точки»:

- **Импорт с Яндекс.Карт** — пришлите ссылку на организацию (`yandex.ru/maps/…`, `maps.yandex.ru/…`, короткую `yandex.ru/maps/-/…`): бот прочитает карточку и прайс, покажет, что понял, и сохранит после подтверждения. Если не получилось (капча, ошибка Яндекса, сбой ИИ), мастер видит только просьбу прислать скриншоты карточки и прайса или текст, а владелец бота получает техническую причину: что ответил Яндекс на каждый запрос (HTTP-статус, итоговый адрес после редиректов, капча), что сказал ИИ и чем закончился запасной путь через web_fetch. Те же строки пишутся в лог: `Яндекс.Карты: … → Карточка: HTTP …` и `Импорт с Яндекс.Карт не удался: …`.
- **Правки словами** — «стрижка теперь 2000», «по воскресеньям выходной», можно прислать фото прайса.
- **Знания** — любые заметки: парковка, оплата, правила опоздания, акции. Бот отвечает по ним клиентам. Когда мастер возвращает диалог боту, свой ответ клиенту можно одной кнопкой сохранить в знания.
- **Длина слота** (15–60 мин) и демо-занятость.
- **Пригласить мастера** (только владелец) — одноразовая ссылка на 7 дней. Мастер открывает её, становится администратором и сразу получает предложение прислать ссылку на свою точку с Яндекс.Карт.
- **Сброс** (только владелец) — вернуть демо-данные, чтобы передать бота другому мастеру.

## Настройки

Основные переменные — в `.env.example`. Тонкая настройка: модель (`ANTHROPIC_MODEL`, по умолчанию `claude-opus-5-5`), скорость (`ANTHROPIC_EFFORT=low`), таймаут ИИ (`LLM_TIMEOUT_MS`), порог уверенности (`CONFIDENCE_THRESHOLD`), скорость «печатает…» (`TYPING_*`).

```
bot/assistant.js  — промпт, инструменты (слоты, запись, отмена), ответ ИИ
bot/schedule.js   — слоты и записи
bot/shop.js       — данные точки (демо, нормализация)
bot/setup.js      — импорт точки с Яндекс.Карт и правки словами/фото
bot/yandex.js     — загрузка карточки организации
test/             — тесты: npm test
```
