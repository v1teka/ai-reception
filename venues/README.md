# Заведения, подготовленные заранее

Файл `venues/<ссылка>.json` — одно заведение. При запуске бот создаёт по каждому новому файлу заведение и присылает владельцу в Telegram ссылку для клиентов и одноразовую ссылку для администратора. По каждому файлу заведение создаётся один раз: правки файла потом ни на что не влияют (данные дальше меняют в «Настройках точки»), а удалённое заведение по нему не вернётся.

Имя файла — ссылка для клиентов: `borodach.json` → `https://t.me/<бот>?start=borodach`. Только латиница в нижнем регистре, цифры и дефис, без общих слов вроде `barbershop` и `salon`.

> Репозиторий публичный. В файлах — только то, что и так видно в карточке на картах (Яндекс.Карты, 2ГИС). Токены ботов, Telegram ID и ссылки-приглашения (`adm_…`, `own_…`) сюда не кладите.

Проверить файл до PR: `node bot/cli.js check venues/borodach.json`.

## Формат

Тот же, что бот получает от ИИ при импорте с карт, плюс несколько необязательных полей:

```json
{
  "name": "Барбершоп «Бородач»",
  "source": "https://yandex.ru/maps/org/borodach/1234567890/",
  "city": "Москва",
  "address": "Тверская ул., 1",
  "phone": "+7 (495) 000-00-00",
  "site": "",
  "description": "Мужские стрижки и бритьё в центре.",
  "timezone": "Europe/Moscow",
  "slot_minutes": 30,
  "hours": [
    { "day": "mon", "closed": false, "open": "10:00", "close": "21:00" },
    { "day": "tue", "closed": false, "open": "10:00", "close": "21:00" },
    { "day": "wed", "closed": false, "open": "10:00", "close": "21:00" },
    { "day": "thu", "closed": false, "open": "10:00", "close": "21:00" },
    { "day": "fri", "closed": false, "open": "10:00", "close": "21:00" },
    { "day": "sat", "closed": false, "open": "11:00", "close": "20:00" },
    { "day": "sun", "closed": true, "open": "", "close": "" }
  ],
  "staff": ["Руслан", "Артём"],
  "services": [
    { "name": "Мужская стрижка", "price": "1 800 ₽", "duration_minutes": 60, "slots": 2, "description": "" },
    { "name": "Борода", "price": "900 ₽", "duration_minutes": 30, "slots": 1, "description": "Оформление и уход" }
  ],
  "knowledge": ["Оплата картой и наличными", "Парковка во дворе"],
  "notes": ["Имена мастеров в карточке не указаны — проверьте"]
}
```

| Поле | Что это |
|---|---|
| `name` | Название — единственное обязательное поле |
| `source` | Ссылка на карточку в Яндекс.Картах или 2ГИС: мастер увидит её в «Настройках точки» |
| `slug` | Ссылка для клиентов, если она должна отличаться от имени файла |
| `timezone` | Часовой пояс заведения, по умолчанию `Europe/Moscow`. По нему бот считает «сегодня», свободное время и напоминания: точке в Алматы — `Asia/Almaty`, в Екатеринбурге — `Asia/Yekaterinburg` |
| `slot_minutes` | Шаг записи в минутах |
| `hours` | Все 7 дней, `mon`…`sun`; выходной — `"closed": true`, до полуночи — `"close": "24:00"`. Графика не нашлось — поле не пишите: без графика бот не записывает и про часы зовёт администратора, а владелец увидит это в «Проверьте» |
| `staff` | Имена мастеров |
| `services` | Услуги: `price` — как в прайсе («от 2 000 ₽»), `slots` — сколько шагов записи занимает услуга |
| `knowledge` | Факты для ответов клиентам: оплата, парковка, правила, акции. Одна строка — один факт |
| `notes` | Что проверить: придёт владельцу вместе со ссылками. К ним бот сам добавит проверки данных: нет графика, услуг, цен, имён мастеров |
| `demo_busy` | `false` — без демо-занятости в расписании (по умолчанию она есть, как у новой точки) |

Чего нет в карточке — не пишите: бот отвечает клиентам по этим данным, а то, чего не знает, передаёт мастеру.
