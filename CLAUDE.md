# Заметки для Claude

Проект — демо AI-администратора: веб-чат (`server.js`, `api/`, `lib/`) и Telegram-бот для барбершопов (`bot/`). Устройство бота и команды — в [README.md](README.md). Тесты: `npm test` (без сети: Telegram и Anthropic API — фейковые серверы из `test/fakes.js`).

## Новое заведение по карточке на картах (Яндекс.Карты или 2ГИС)

Когда присылают ссылку на карточку и просят завести бота для заведения:

1. Прочитай карточку и её прайс. Быстрее всего — тем же разбором, что у бота: он печатает текст карточки и прайса, график (`hours`) и часовой пояс (`timezone`), короткие ссылки раскрывает сам:
   `node -e 'require("./bot/maps").mapOf(process.argv[1]).fetch(process.argv[1]).then((r) => console.log(r.ok ? [r.text, JSON.stringify(r.hours), r.timezone, JSON.stringify(r.checks)].join("\n\n") : r))' '<ссылка>'`
   Если карты не отдают страницу, попроси скриншоты карточки и прайса или текст.
   - **Яндекс.Карты.** Прайс — адрес карточки + `prices/`. График на карточке свёрнут: в тексте видно только «Открыто до 22:00» — это состояние на момент загрузки, а не график. Полный график — в HTML карточки (сырой HTML, не текст WebFetch): тег `<meta itemProp="openingHours" content="Mo 10:00-22:00"/>` на каждый рабочий день, дня нет — выходной, перерыв — через запятую, закрытие раньше открытия — работа после полуночи. Смещение часового пояса — `"tzOffset"` в секундах.
   - **2ГИС.** Всё из карточки — в сыром HTML, в `var initialState = JSON.parse('…')` → `data.entity.profile[<номер>].data`: `name_ex.primary`, `address_name`, `contact_groups`, `schedule` (`Mon`…`Sun` → `working_hours: [{ from, to }]`; дня нет — выходной, несколько промежутков — перерыв, `to` раньше `from` — работа после полуночи), `timezone_offset` в минутах, `attribute_groups` (оплата, удобства). Прайс — адрес карточки + `/tab/prices`, там же в `data.market`: названия — в `products`, цены — в `offers`; страница отдаёт первые 50 позиций. Браузеры старых версий 2ГИС отправляет на заглушку `/museum` («Ваш браузер устарел») — нужен User-Agent свежего Chrome.
   - Графика не нашёл — `hours` не пиши и не угадывай: бот сам предупредит, что графика нет. Точка не в Москве — укажи `timezone` (Алматы — `Asia/Almaty`, Екатеринбург — `Asia/Yekaterinburg`): по нему бот считает время записи.
2. Положи данные в `venues/<ссылка>.json` по формату из [venues/README.md](venues/README.md). Ссылка — латиницей по названию, без общих слов (`barbershop`, `salon`), как делает `slugify` в `bot/util.js`, и не занята другим файлом в `venues/`. Ничего не придумывай: чего нет в карточке — не пиши, сомнительное — в `notes`.
3. Проверь: `node bot/cli.js check venues/<ссылка>.json` и `npm test`.
4. Открой PR. После мержа в `main` автодеплой выкладывает бота; при запуске бот создаёт заведение и присылает владельцу в Telegram ссылку для клиентов и одноразовую ссылку для администратора.

Если у тебя есть доступ к серверу с ботом (Remote Control, SSH) — можно без PR: `docker exec <контейнер> node bot/cli.js add <ссылка на карточку в Яндекс.Картах или 2ГИС>` (бот сам загрузит карточку) или `add <файл.json>`. Ссылки будут в ответе команды и у владельца в Telegram. Остальное — `node bot/cli.js help`: ссылки администратора, назначить администратора по Telegram ID, отдельный бот заведения.

## Чего не делать

- Репозиторий публичный: не коммить токены ботов, ключи, Telegram ID людей, ссылки-приглашения `adm_…` и `own_…`.
- Не меняй расположение `data/state.json`: это данные первого заведения, по ним работает откат на прежнюю версию.
