# Заметки для Claude

Проект — демо AI-администратора: веб-чат (`server.js`, `api/`, `lib/`) и Telegram-бот для барбершопов (`bot/`). Устройство бота и команды — в [README.md](README.md). Тесты: `npm test` (без сети: Telegram и Anthropic API — фейковые серверы из `test/fakes.js`).

## Новое заведение по карточке с Яндекс.Карт

Когда присылают ссылку на карточку и просят завести бота для заведения:

1. Прочитай карточку (WebFetch) и вкладку с ценами — адрес карточки + `prices/`. Короткую ссылку `yandex.ru/maps/-/…` сначала раскрой. Если Яндекс не отдаёт страницу, попроси скриншоты карточки и прайса или текст.
2. Положи данные в `venues/<ссылка>.json` по формату из [venues/README.md](venues/README.md). Ссылка — латиницей по названию, без общих слов (`barbershop`, `salon`), как делает `slugify` в `bot/util.js`, и не занята другим файлом в `venues/`. Ничего не придумывай: чего нет в карточке — не пиши, сомнительное — в `notes`.
3. Проверь: `node bot/cli.js check venues/<ссылка>.json` и `npm test`.
4. Открой PR. После мержа в `main` автодеплой выкладывает бота; при запуске бот создаёт заведение и присылает владельцу в Telegram ссылку для клиентов и одноразовую ссылку для администратора.

Если у тебя есть доступ к серверу с ботом (Remote Control, SSH) — можно без PR: `docker exec <контейнер> node bot/cli.js add <ссылка на карточку>` (бот сам загрузит карточку) или `add <файл.json>`. Ссылки будут в ответе команды и у владельца в Telegram. Остальное — `node bot/cli.js help`: ссылки администратора, назначить администратора по Telegram ID, отдельный бот заведения.

## Чего не делать

- Репозиторий публичный: не коммить токены ботов, ключи, Telegram ID людей, ссылки-приглашения `adm_…` и `own_…`.
- Не меняй расположение `data/state.json`: это данные первого заведения, по ним работает откат на прежнюю версию.
